💻 Tecnologie di Oreste AI

Le tecnologie che permettono il funzionamento dell'assistente vocale italiano.

💻 HTML

Struttura delle pagine web e organizzazione dei contenuti.

🎨 CSS

Grafica, colori e interfaccia del progetto.

⚙️ JavaScript

Gestione della logica dell'assistente e dei comandi vocali.

🎤 Web Speech API

Tecnologia utilizzata per il riconoscimento della voce e la sintesi vocale.

🌐 API Web

Collegamento a servizi esterni come meteo e ricerca sul web.

🤖 Intelligenza artificiale

Gestione delle richieste dell'utente e sviluppo di nuove funzionalità.

🚀 Sviluppo continuo

Oreste AI è un progetto in continua evoluzione con nuove funzioni e aggiornamenti futuri.
