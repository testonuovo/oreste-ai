# Oreste AI – Code Signing Policy

## Code Signing

Oreste AI uses code signing to help users verify the authenticity
and integrity of released Windows software.

The code signing certificate for eligible open-source releases is
provided through the SignPath Foundation.

## Source Code

All source code used to produce signed releases is available in this
GitHub repository:

https://github.com/testonuovo/oreste-ai

## Roles

### Authors
Oreste AI contributors who create and maintain the source code.

### Reviewers
Contributors responsible for reviewing source code and changes before
a release is signed.

### Approvers
Authorized maintainers responsible for approving releases for signing.

## Build and Release

Signed binaries are built from the source code contained in this
repository and published through the official Oreste AI GitHub Releases.

## Privacy

The project does not intentionally include personal information in
released binaries.
