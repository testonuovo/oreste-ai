Cos’è un assistente vocale web


Un assistente vocale web è un software che funziona direttamente nel browser e permette di interagire con la voce.

A differenza delle app tradizionali, non richiede installazione e usa le API del browser.


Web Speech API


La Web Speech API permette ai browser di riconoscere e generare voce.

È composta da due parti: - SpeechRecognition - SpeechSynthesis


Assistenti vocali: browser vs app


Browser

Non richiede installazione, funziona subito e usa Web API.

App

Più potenti ma richiedono installazione e permessi.
