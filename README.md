## 🚀 Cos’è Oreste AI

Oreste AI è un assistente vocale italiano creato da Oreste De Chiara.  
Funziona direttamente nel browser senza installazione.

Permette di usare comandi vocali e testuali per controllare il web.

---

## 🔥 Funzioni principali

- 🎤 Riconoscimento vocale (parlare con il browser)
- 🔊 Risposta vocale automatica
- 🌐 Apertura siti web (Google, YouTube, Canva, ecc.)
- 🔎 Ricerca su Google tramite voce o testo
- 💬 Chat interattiva
- 📱 Compatibile con PC e smartphone
